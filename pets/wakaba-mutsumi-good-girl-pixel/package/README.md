# 好女孩 · 若叶睦

面无表情，瓜事很多。一个保留“好女孩”梗图裁切、黑色外轮廓、右下角像素圆弧和原 12 色配色的像素桌宠。

## 查看动画

打开同目录的 `preview.html`，可以选择九种动作和十六个注视方向，暂停、逐帧查看，或切换深浅背景。`previews/` 内有九种动作与十六向注视的透明 GIF，均从本包的正式图集裁帧导出。

## 导入

本文件夹是完整宠物包；`pet.json` 与 `spritesheet.png` 应保持在同一目录。

- Codex 兼容客户端：将整个 `wakaba-mutsumi-good-girl-pixel` 文件夹放进其自定义宠物目录。常见位置为 `~/.codex/pets/`；配置了 `CODEX_HOME` 时，以该目录下的 `pets/` 为准。
- PetDex：将整个文件夹放进 `~/.petdex/pets/`，或通过客户端的本地宠物导入入口选择该文件夹。
- 刷新或重新打开宠物列表，选择“若叶睦 · 好女孩”。文件已放入目录与实际选中启用是两个步骤。

为使气泡文字达到 12px，桌宠显示宽度请设为至少 96px；预览页的最小显示宽度为 128px。

使用本包不要求存在 `codex` 命令。具体目录发现、状态触发、播放速度和十六向注视支持取决于客户端；PetDex 当前项目文档列出了九种原生动作，v2 的额外两行供支持注视的客户端使用。

## 素材规格

| 项目 | 内容 |
| --- | --- |
| 作品版本 | v1.0 |
| 格式 | Sprite v2，透明静态 PNG |
| 图集 | 1536 × 2288，8 列 × 11 行 |
| 每帧 | 192 × 208 |
| 九种动作有效帧数 | 6、8、8、4、5、8、6、6、6 |
| 注视 | 16 方向，上方起始、顺时针，每格 22.5° |

| 眼睛与嘴巴 | 所有动作双眼睁开；没有嘴巴 |

## 来源

角色及作品：Bushiroad / BanG Dream!。像素底图来自用户指定的[拼豆图鉴页面](https://pd.anqstar.com/drawings/drw_0a1c7d99d3e7cad76f807dff401fc335)，页面发布者为 huolizi；原插画作者与首发出处未核实。像素编辑、动画与打包由 Codex 按用户确认方案用代码完成，未使用 ImageGen。

“祥 移动”“不会长久的”采用社区传播的台词；“太好了呢”是“真是太好了呢”的缩写；“好女孩?”沿用用户指定社区梗。退货、种瓜文案及具体道具互动属于本作品的二创设计。
